屏幕色彩测试

选择测试场景后可预览；进入全屏便于排查坏点、色差与亮度均匀性。全屏内左右半屏点击或方向键切换，Esc 退出。

预览区可聚焦后使用 ← → 切换场景；全屏内左右半屏点击同样可切换，Esc 退出全屏。

测试场景

提供纯白、纯黑、三原色、渐变与棋盘格等测试画面，支持全屏切换，便于排查坏点、色差与亮度均匀性；Esc 退出全屏。

使用说明

选择测试场景后可预览，进入全屏后左右半屏点击或方向键切换画面，按 Esc 退出。所有渲染均在浏览器本地完成。

  1. 01在色板中选择要查看的测试场景（如纯白、纯黑、三原色、棋盘格）。
  2. 02点击「进入全屏」铺满整个屏幕，便于观察坏点与色差。
  3. 03全屏内点击左/右半屏或按方向键切换场景，按 Esc 退出全屏。

常见问题

点击问题展开或收起答案

如何判断是否有坏点？

在纯白或纯黑全屏下观察是否有常亮或常暗的像素点；棋盘格与渐变可辅助发现局部偏色或亮度不均。

全屏无法开启怎么办？

部分浏览器需用户手势触发全屏；若仍失败，可最大化浏览器窗口后使用预览区进行粗略检查。
