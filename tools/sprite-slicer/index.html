使用说明

把精灵图拆成独立素材。可选择规则网格，或上传 TexturePacker JSON、Cocos2d plist 定位文件按帧裁切；旋转帧会自动还原方向。

  1. 01导入静态 Sprite Sheet 图片。
  2. 02选择「规则网格」并填写行列与间距，或选择「Texture Atlas 定位文件」并上传 JSON / plist。
  3. 03开始切图，预览各个切片，逐张下载或打包为 ZIP。

常见问题

点击问题展开或收起答案

支持哪些 Texture Atlas 定位文件？

支持 TexturePacker 导出的 JSON（hash 或 array 格式）以及 Cocos2d plist。工具按 frame 坐标裁切，旋转帧会还原为原始方向，输出文件名与定位文件中的帧名一致。

为什么提示网格无法整除？

原图扣除两侧外边距和格子间距后，需要能被行列数整除。请检查参数或原图尺寸，工具不会悄悄舍弃剩余边缘。单次最多导出 256 张。
