IP 计算器

IPv4 / IPv6 / CIDR
  • 协议版本IPv4
  • 地址192.168.1.10
  • 前缀/24
  • 子网掩码255.255.255.0
  • 反掩码0.0.0.255
  • 网络地址192.168.1.0
  • 广播地址192.168.1.255
  • 首个可用主机192.168.1.1
  • 末个可用主机192.168.1.254
  • 地址总数256
  • 可用主机数254
  • 分类C 类（传统分类，仅供参考）

支持 IPv4 / IPv6 与 CIDR，计算网络前缀、地址范围；IPv4 含广播与可用主机数。

使用说明

输入如 192.168.1.10/24 或 2001:db8::/32 的地址，快速得到子网划分信息。

  1. 01输入 IPv4、IPv6 或 CIDR。
  2. 02点击计算或等待自动处理。
  3. 03查看网段信息并复制。

IPv6 与 IPv4 有何不同？

IPv6 无广播地址概念，结果展示网络前缀、首个/末个地址与地址范围说明；IPv4 仍包含掩码、广播与可用主机数。
