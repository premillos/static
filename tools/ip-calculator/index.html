支持 IPv4 与 CIDR 表示，计算网络地址、广播地址与可用主机范围。

使用说明

输入如 192.168.1.10/24 的地址，快速得到子网划分信息。

  1. 01输入 IPv4 或 CIDR。
  2. 02点击计算。
  3. 03查看网段信息并复制。
