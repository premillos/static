检查或安装 Chrome CORS 助手

未检测到 CORS 助手。可能尚未安装、未允许访问当前站点，或页面需要刷新。

  1. 点击“下载 CORS 助手”，将下载的 ZIP 文件解压到本地文件夹。
  2. 在 Chrome 地址栏粘贴并打开： chrome://extensions/
  3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的解压目录。
  4. 确认扩展已启用，再刷新当前工具页面，重新点击“发送请求”。

网页无法区分未安装与站点权限受限。已安装时请检查扩展的站点访问权限，再刷新页面。
