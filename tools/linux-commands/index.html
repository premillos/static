Linux 常用命令

搜索
分组

共 61 条

  • 文件与目录列出目录
    ls -lah
    • -l 长格式（权限/大小）
    • -a 含隐藏文件
    • -h 人类可读大小
    • -t 按修改时间排序
    • -R 递归子目录

    查看当前或指定目录内容，日常排查首选。

  • 文件与目录切换目录
    cd /path/to/dir
    • cd ~ 回到主目录
    • cd - 返回上次目录
    • cd .. 上一级

    改变当前工作目录；路径含空格时需加引号。

  • 文件与目录显示当前路径
    pwd
    • -P 显示物理路径（解析软链）
    • -L 显示逻辑路径（默认）

    输出当前工作目录绝对路径，写脚本或排查路径时常用。

  • 文件与目录创建目录
    mkdir -p project/src/utils
    • -p 递归创建多级目录
    • -m 指定权限如 755

    已存在的中间目录不会报错。

  • 文件与目录创建空文件 / 更新时间
    touch file.txt
    • -a 只改访问时间
    • -m 只改修改时间
    • -c 文件不存在时不创建

    快速创建占位文件或批量刷新时间戳。

  • 文件与目录复制
    cp -a source/ dest/
    • -r/-R 递归目录
    • -a 归档（权限/时间/链接）
    • -u 仅复制较新文件
    • -v 显示过程
    • -i 覆盖前确认

    复制文件或目录；备份目录推荐 cp -a。

  • 文件与目录移动 / 重命名
    mv old.txt new.txt
    • -i 覆盖前确认
    • -u 目标较新时不覆盖
    • -v 显示过程

    同一文件系统内移动相当于重命名。

  • 文件与目录删除
    rm -rf dirname
    • -r 递归目录
    • -f 强制不提示
    • -i 删除前确认
    • -v 显示过程

    不可恢复，删除前务必确认路径，慎用 rm -rf。

  • 文件与目录创建软链接
    ln -s /path/target link-name
    • -s 符号链接
    • -f 强制覆盖已有链接

    ln 无 -s 为硬链接；部署时常用软链指向版本目录。

  • 文件与目录查找文件
    find . -type f -name "*.log" -mtime -7
    • -name 名称通配
    • -type f 文件 / d 目录
    • -mtime -7 近 7 天修改
    • -size +100M 大于 100M
    • -exec cmd {} \; 对结果执行命令

    从指定目录递归查找，可组合多种条件。

  • 文件与目录查看 inode 详情
    stat file.txt
    • -c 自定义输出格式
    • -f 查看文件系统信息

    显示大小、权限、时间戳、inode 等元数据。

  • 文件与目录树形展示目录
    tree -L 2 src/
    • -L 限制层级深度
    • -a 含隐藏文件
    • -d 仅目录
    • -h 人类可读大小

    需安装 tree；未安装可用 find 替代。

  • 权限与用户修改权限
    chmod 755 script.sh
    • 755 rwxr-xr-x 常用脚本
    • 644 rw-r--r-- 常用文件
    • u+x 给拥有者加执行
    • -R 递归目录

    数字模式或 u/g/o/a 符号模式均可。

  • 权限与用户修改拥有者
    chown user:group file
    • -R 递归目录
    • user:group 同时改用户和组
    • user. 只改用户

    通常需要 root 或 sudo。

  • 权限与用户修改所属组
    chgrp www-data file
    • -R 递归目录

    仅变更用户组。

  • 权限与用户提权执行
    sudo command
    • -i 模拟 root 登录 shell
    • -u user 以指定用户运行
    • -l 列出当前用户可用命令

    临时获取管理员权限；操作前确认命令影响范围。

  • 权限与用户当前用户
    whoami

    输出当前有效用户名。

  • 权限与用户用户 ID 与组
    id
    • -u 仅 UID
    • -g 仅 GID
    • -G 所有附加组

    排查权限问题时确认当前身份。

  • 文本处理搜索文本
    grep -rn "keyword" .
    • -r 递归目录
    • -n 显示行号
    • -i 忽略大小写
    • -v 反向匹配
    • -E 扩展正则
    • --color=auto 高亮
    • -C 3 上下文 3 行

    日志与代码搜索最常用工具之一。

  • 文本处理输出文件内容
    cat file.txt
    • -n 显示行号
    • -A 显示不可见字符

    适合小文件；大文件请用 less。

  • 文本处理分页查看
    less large.log
    • /keyword 搜索
    • n/N 上/下一个匹配
    • G 跳到末尾
    • q 退出

    只读分页浏览，不会一次性载入全部内容到终端。

  • 文本处理查看头 / 尾
    tail -n 100 -f app.log
    • -n 行数
    • -f 持续跟踪追加（tail）
    • head 默认前 10 行

    快速看日志开头或末尾；tail -f 实时跟踪。

  • 文本处理统计行 / 词 / 字节
    wc -l file.log
    • -l 行数
    • -w 词数
    • -c 字节数
    • -m 字符数

    统计文件或管道输出规模。

  • 文本处理排序与去重
    sort access.log | uniq -c | sort -nr
    • sort -n 数字排序
    • sort -r 逆序
    • sort -k2 按第 2 列
    • uniq -c 计数
    • uniq -d 仅重复行

    常配合管道做简单日志统计。

  • 文本处理按列截取
    cut -d',' -f1,3 data.csv
    • -d 分隔符
    • -f 字段号或范围
    • -c 按字符位置

    处理 CSV 或固定分隔日志。

  • 文本处理流式编辑
    sed -i 's/old/new/g' file.txt
    • s/old/new/g 全局替换
    • -i 原地修改
    • -n 静默
    • -e 多条表达式
    • 1,10d 删除 1-10 行

    Linux 与 macOS 的 sed -i 语法略有差异。

  • 文本处理按列处理
    awk '{print $1, $3}' access.log
    • $0 整行
    • $1 第一列
    • -F: 指定分隔符
    • NR==1 首行
    • END{} 结束后执行

    适合提取字段、简单汇总与格式化输出。

  • 文本处理批量执行
    find . -name "*.tmp" | xargs rm -f
    • -0 配合 find -print0
    • -I{} 占位替换
    • -P 4 并行 4 进程
    • -n 1 每条输入执行一次

    将标准输入转为命令参数，避免参数过长。

  • 管道与重定向管道与重定向
    cmd1 | cmd2 > out.log 2>&1
    • | 管道传 stdout
    • > 覆盖写文件
    • >> 追加写
    • 2>&1 错误合并到 stdout
    • < file 输入重定向
    • && 前命令成功才执行后命令
    • || 前命令失败才执行

    组合多个命令与输出控制的基础语法。

  • 管道与重定向同时输出屏幕与文件
    command | tee output.log
    • -a 追加模式
    • -i 忽略中断

    调试时既想看终端输出又想保存日志。

  • 进程与服务查看进程
    ps aux | grep nginx
    • aux 所有用户详细列表
    • -ef 标准格式
    • -p PID 指定进程
    • --sort=-%mem 按内存排序

    配合 grep 过滤；实时动态用 top / htop。

  • 进程与服务实时资源监控
    top
    • P 按 CPU 排序
    • M 按内存排序
    • k 杀死进程
    • 1 显示各 CPU 核
    • q 退出

    交互式查看 CPU、内存与进程。

  • 进程与服务发送信号
    kill -15 PID
    • -15 SIGTERM 正常终止（默认）
    • -9 SIGKILL 强制杀死
    • -HUP 重载配置（部分服务）
    • killall 进程名

    先用 ps / pgrep 确认 PID，优先 -15 再考虑 -9。

  • 进程与服务systemd 服务管理
    systemctl status nginx
    • start 启动
    • stop 停止
    • restart 重启
    • reload 重载配置
    • enable 开机自启
    • disable 取消自启
    • is-active 是否运行

    适用于使用 systemd 的发行版（CentOS 7+、Ubuntu 16+ 等）。

  • 进程与服务systemd 日志
    journalctl -u nginx -f
    • -u 指定单元
    • -f 跟踪
    • -n 100 最近 100 行
    • --since today 时间范围
    • -p err 仅错误级别

    查看系统与服务日志，替代部分 /var/log 排查。

  • 进程与服务后台常驻运行
    nohup ./app.sh > app.log 2>&1 &
    • & 放后台
    • 2>&1 合并错误输出
    • disown 脱离终端任务

    SSH 断开后进程继续运行；生产环境更推荐 systemd。

  • 网络HTTP 客户端
    curl -I https://example.com
    • -I 仅响应头
    • -L 跟随重定向
    • -o file 保存到文件
    • -O 按 URL 文件名保存
    • -X POST 指定方法
    • -H "Key: Val" 请求头
    • -d "a=1" POST 数据
    • -v 详细调试

    接口调试、下载与健康检查常用。

  • 网络下载文件
    wget -c https://example.com/file.zip
    • -c 断点续传
    • -O 指定文件名
    • -r 递归镜像
    • -q 安静模式
    • --limit-rate=1m 限速

    适合脚本化批量下载。

  • 网络连通性测试
    ping -c 4 example.com
    • -c 次数
    • -i 间隔秒
    • -W 超时秒

    测试网络可达与延迟。

  • 网络套接字 / 端口
    ss -lntp
    • -l 监听中
    • -n 数字显示端口
    • -t TCP
    • -u UDP
    • -p 显示进程
    • sport = :80 过滤端口

    现代替代 netstat；排查端口占用首选。

  • 网络网络接口
    ip addr show
    • addr 查看 IP
    • link 查看网卡
    • route 路由表
    • a 全部

    替代 ifconfig 的 iproute2 工具。

  • 网络SSH 复制文件
    scp -r local/ user@host:/remote/path/
    • -r 递归目录
    • -P 端口（大写）
    • -i 私钥文件
    • -C 压缩传输

    基于 SSH 的安全复制。

  • 网络增量同步
    rsync -avz --delete src/ user@host:dest/
    • -a 归档模式
    • -v 详细
    • -z 压缩传输
    • --delete 删除目标多余文件
    • -n 试运行
    • --exclude 排除规则

    目录同步与备份；末尾 / 表示目录内容。

  • 网络远程登录
    ssh user@host
    • -p 端口
    • -i 私钥
    • -L 本地端口转发
    • -N 不执行远程命令（配合转发）
    • -f 后台

    安全远程 shell 与隧道基础。

  • 磁盘与系统磁盘空间
    df -hT
    • -h 人类可读
    • -T 显示文件系统类型
    • -i inode 使用率

    查看各挂载点剩余空间。

  • 磁盘与系统目录占用
    du -sh * | sort -hr
    • -s 汇总
    • -h 人类可读
    • -d 1 深度一层
    • --max-depth=1 同 -d 1

    定位哪个目录占用最多空间。

  • 磁盘与系统内存使用
    free -h
    • -h 人类可读
    • -m 以 MB 显示
    • -s 3 每 3 秒刷新

    查看物理内存与 swap。

  • 磁盘与系统内核信息
    uname -a
    • -r 内核版本
    • -m 机器架构
    • -s 系统名称

    快速确认系统版本与架构。

  • 磁盘与系统打开的文件
    lsof -i :8080
    • -i :端口 端口占用
    • -p PID 指定进程
    • -u user 指定用户
    • +D dir 目录下打开文件

    排查端口被谁占用、文件被哪个进程持有。

  • 磁盘与系统挂载点
    mount | column -t
    • -t nfs 按类型过滤
    • mount -a 挂载 fstab 全部

    查看或管理文件系统挂载。

  • 磁盘与系统环境变量
    env | grep PATH
    • export VAR=val 设置并导出
    • unset VAR 删除
    • echo $VAR 读取

    查看与设置进程环境。

  • 磁盘与系统定时任务
    crontab -e
    • -e 编辑
    • -l 列出
    • -r 删除当前用户任务
    • -u user 指定用户（需 root）

    用户级 cron；系统级任务见 /etc/cron.d。

  • 压缩归档tar 打包
    tar -czf backup.tar.gz folder/
    • -c 创建
    • -x 解压
    • -t 列表
    • -z gzip
    • -j bzip2
    • -v 详细
    • -f 指定文件名
    • -C dir 解压到目录

    解压示例：tar -xzf backup.tar.gz -C /dest/

  • 压缩归档zip 压缩
    zip -r archive.zip folder/
    • -r 递归
    • -9 最高压缩
    • -q 安静
    • unzip archive.zip 解压
    • unzip -l 列表

    与 Windows 交互时常用 zip 格式。

  • Git 常用工作区状态
    git status
    • -s 简短格式
    • -u 显示未跟踪文件

    查看修改、暂存与未跟踪文件。

  • Git 常用提交历史
    git log --oneline -10
    • --oneline 单行
    • -10 最近 10 条
    • --graph 图形分支
    • -p 显示 diff
    • --author 过滤作者

    追溯变更记录。

  • Git 常用查看差异
    git diff
    • --staged / --cached 暂存区
    • HEAD~1 与上一提交比
    • file 指定文件

    对比工作区、暂存区与历史版本。

  • Git 常用分支管理
    git branch -a
    • -a 含远程分支
    • -d 删除已合并分支
    • -D 强制删除
    • git checkout -b feat 创建并切换

    现代 Git 亦可用 git switch / git branch -c。

  • Git 常用拉取 / 推送
    git pull --rebase origin main
    • pull 拉取合并
    • push 推送到远程
    • --rebase 变基拉取
    • -u origin branch 首次推送并关联

    与远程仓库同步代码。

  • Git 常用暂存修改
    git stash push -m "wip"
    • list 列表
    • pop 恢复并删除
    • apply 恢复不删除
    • drop 丢弃

    临时切换分支前保存未提交改动。

  • Git 常用重置提交
    git reset --soft HEAD~1
    • --soft 保留工作区与暂存
    • --mixed 默认保留工作区
    • --hard 全部丢弃（危险）

    撤销提交或回退版本，--hard 不可恢复需谨慎。

常见问题

点击问题展开或收起答案

可以直接在生产服务器执行吗？

请先理解命令作用，尤其是 rm、chmod、kill 等具有破坏性或权限影响的命令。建议在测试环境验证后再用于生产。

为什么有些命令需要 sudo？

修改系统配置、管理其他用户进程或写入系统目录通常需要管理员权限，普通用户无法直接执行。
