Lottie JSON 与 .lottie 压缩包均在浏览器本地解析与播放，不上传文件；支持 SVG/Canvas 渲染与速度调节。

使用说明

预览 Lottie 动画 JSON，调节循环、速度与背景色。所有解析与渲染均在本地完成。

  1. 01选择上传 .json 文件，或切换到「粘贴 JSON」直接粘贴动画数据。
  2. 02点击「加载动画」或选择文件后自动加载，在预览区查看效果。
  3. 03使用播放/暂停/停止控制，调整速度、循环与渲染器。

常见问题

点击问题展开或收起答案

支持哪些 Lottie 文件？

支持标准 Lottie JSON（含 v 与 layers/assets 字段），以及 .lottie 压缩包（自动解压并加载首个动画）。

SVG 和 Canvas 渲染有什么区别？

SVG 默认更清晰，适合图标与 UI 动画；Canvas 在复杂动画上可能更流畅。切换渲染器会重新加载动画。

动画会上传到服务器吗？

不会。文件读取与动画渲染都在浏览器本地完成。
