OCR 文字识别

01 / 选择图片

识别语言

在浏览器本地 OCR；首次使用需下载中文/英文语言包，之后浏览器会缓存。

02 / 预览与结果

上传图片后将在此预览并叠加词块边框。

使用说明

适合扫描文档截图、标牌、票据与屏幕截图中的文字提取。选择语言后点击开始识别，可在预览图上查看词块边框，并复制纯文本或完整报告。

  1. 01上传 PNG / JPG / WebP 静态图片（单张最大 20 MB）。
  2. 02选择识别语言：简体中文、英文或中英混合。
  3. 03点击开始识别；首次使用会下载对应语言包（需联网一次，之后浏览器会缓存）。
  4. 04复制识别文本或完整报告。

常见问题

点击问题展开或收起答案

支持哪些语言？

当前仅支持简体中文（chi_sim）、英文（eng）及两者混合识别，不包含繁体或其他语言。

识别准确率如何？

取决于图片清晰度、对比度与字体。建议尽量使用正向、无严重模糊的文字图片；手写体识别效果可能较差。

需要联网吗？

首次加载某种语言包时需要从 CDN 下载 traineddata；识别过程在本地完成。语言包缓存后可离线重复使用。

图片会上传吗？

不会。OCR 在浏览器本地执行，图片与识别结果均不会发送到服务器。
