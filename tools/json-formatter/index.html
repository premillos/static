常见问题

对比模式如何判断差异？

工具会递归比较对象与数组，按路径列出修改、新增、删除与类型不同四类差异，并展示两侧具体值；下方提供格式化并排预览，便于对照查看。

合并模式如何覆盖字段？

以 JSON A 为基础，递归深合并 JSON B：对象会合并键，冲突的基础类型值由 B 覆盖；数组可选按索引深合并、整体替换或拼接；两侧类型不一致时采用 B 的值。

生成的 Go / TypeScript 类型准确吗？

工具根据样例 JSON 推断字段类型，数组元素会合并推断；null 字段在 TypeScript 中标记为可空，在 Go 中使用指针类型。复杂或多态数据建议人工复核后再用于生产代码。

JSON 转 TOML / INI 有哪些限制？

根节点需为对象。TOML 不支持 null 与混合类型数组；嵌套对象转为表段，对象数组在 TOML 中使用 [[表名]]。INI 将基础类型数组以逗号写入同一键，对象数组转为 [键.索引] 节；含特殊字符的值会自动加引号。
