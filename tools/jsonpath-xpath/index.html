JSONPath XPath 查询

JSON 输入请输入合法 JSON；支持对象、数组和基础类型根节点。
JSONPath 表达式支持 $、点属性、方括号属性/索引和通配符；不支持递归、过滤器和切片。

查询在浏览器本地执行，不会上传输入内容。

使用说明

适合快速验证数据提取表达式；工具会明确展示匹配结果和语法错误。

  1. 01选择 JSONPath 或 XPath。
  2. 02输入文档和查询表达式。
  3. 03执行并查看匹配结果。
