透明边缘裁切

01 / 选择图片

本地处理，放心使用。
依据 Alpha 通道裁切，输出透明 PNG。白色背景不属于透明区域。留白受原图边界限制，最多 2400 万像素、单边 8192 px。

02 / 设置与导出

透明阈值 · 0
保留边距（px）

阈值为 0 时，仅去除完全透明的边缘。

图片不会上传，处理速度取决于图片大小和设备性能。

使用说明

为 Logo、贴纸和素材去掉多余的透明画布。工具扫描 Alpha 通道，找到有效像素边界，再按所设边距裁切，保留内容的原始像素尺寸。

  1. 01选择带透明边缘的静态图片，单张最大 20 MB。
  2. 02设置透明阈值与保留边距；默认只去除完全透明的边缘。
  3. 03处理后查看裁切尺寸，下载保留透明通道的 PNG。

常见问题

点击问题展开或收起答案

可以自动去掉白色背景吗？

不可以。工具按透明度裁切，不进行抠图或背景识别。白色背景属于不透明像素，因此不会被当作透明边缘去除。

透明阈值和保留边距分别有什么作用？

阈值以下或等于阈值的像素视为透明，可用于忽略很淡的边缘。保留边距在有效边界外保留指定像素，但不超出原图范围；整张图片被判定透明时会提示调整阈值。
