使用说明

适合作品集、素材发布与版权标注。支持文字、Logo 或组合水印；布局含单点、整图/斜向/边缘平铺与居中斜纹大字；可一次处理最多 50 张静态图片并 ZIP 下载。

  1. 01选择快速方案或自定义水印内容（文字、Logo 或两者），调整布局、字体、描边与输出命名。
  2. 02上传一张或多张静态 PNG / JPG / WebP，在实时预览中确认效果。
  3. 03开始处理，预览结果后下载单张或 ZIP。

常见问题

点击问题展开或收起答案

斜向平铺和整图平铺有什么区别？

整图平铺为横平竖直网格重复；斜向平铺会旋转后铺满全图，是常见的防盗水印样式。间距填 0 时按文字宽度自动估算，密度可进一步调节重复疏密。

支持图片 Logo 水印吗？

支持。可上传 PNG / WebP 透明 Logo，选择「仅 Logo」或与文字组合；Logo 大小与位置可单独调整。

批量处理时文字能按文件名变化吗？

可以。水印文字支持 {date}、{filename}、{index} 变量，批量处理时会按每张原文件名与序号替换。

导出 JPG 时透明区域会怎样？

JPG 不支持透明通道，导出前会用白色背景填充；需要保留透明请选 PNG 或 WebP。
