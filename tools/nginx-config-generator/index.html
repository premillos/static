# 预设: SPA 单页应用

# 开启 gzip 压缩
gzip on;
gzip_comp_level 5;
gzip_min_length 256;
gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript image/svg+xml;

server {
    listen 80;
    server_name example.com;

    root /var/www/html;
    index index.html;

    client_max_body_size 20m;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|webp|woff2?|ttf)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

}

使用说明

适合快速搭建 Vue / React 单页应用、静态资源站点或后端 API 反代。生成结果为常用 server 片段，部署前请核对域名、证书路径与 upstream 地址。

  1. 01选择场景预设（SPA、静态、反代或 HTTPS 版本）。
  2. 02填写域名、端口、根目录或 proxy_pass 等参数。
  3. 03生成配置并复制到服务器，执行 nginx -t 后 reload。

生成的配置可以直接用于生产吗？

这是常见场景的起步模板，仍需按你的目录结构、证书文件名、日志路径与安全策略调整。修改后务必先运行 nginx -t 检查语法。

SPA 为什么要 try_files？

前端路由由浏览器接管，直接访问 /about 等路径时 Nginx 需回退到 index.html，否则会出现 404。静态站点不需要此规则。

HTTPS 配置包含哪些内容？

HTTPS 预设会生成 443 ssl 监听块，并可选添加 80 端口 301 跳转。证书与私钥路径需替换为你实际的 fullchain / privkey 文件位置。
