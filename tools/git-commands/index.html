Git 常用命令

搜索
分组

共 24 条

  • 仓库初始化初始化仓库
    git init
    • git init project-name 指定目录
    • --bare 裸仓库（服务器）

    在当前或指定目录创建新的 Git 仓库。

  • 仓库初始化克隆远程仓库
    git clone https://github.com/user/repo.git
    • --depth 1 浅克隆
    • -b branch 指定分支
    • repo dir 克隆到指定目录名

    从远程 URL 复制完整仓库到本地。

  • 日常提交查看状态
    git status
    • -s 简短格式
    • -u 显示未跟踪文件
    • --ignored 显示被忽略文件

    查看工作区、暂存区与未跟踪文件变更。

  • 日常提交添加到暂存区
    git add .
    • . 当前目录全部
    • -p 交互式分块暂存
    • -u 已跟踪文件的修改与删除
    • path 指定文件

    将变更放入暂存区，准备提交。

  • 日常提交提交
    git commit -m "feat: add feature"
    • -m 提交说明
    • -a 跳过 add 直接提交已跟踪文件
    • --amend 修改上一次提交
    • --no-verify 跳过钩子

    将暂存区快照保存到本地仓库。

  • 日常提交查看差异
    git diff
    • --staged / --cached 暂存区
    • HEAD~1 与上一提交比
    • branch -- branch2 分支间比较
    • file 指定文件

    对比工作区、暂存区或历史版本差异。

  • 历史查看提交历史
    git log --oneline -10
    • --oneline 单行
    • -10 最近 10 条
    • --graph 图形分支
    • -p 显示 diff
    • --author 过滤作者
    • --since 时间范围

    查看提交记录与分支演进。

  • 历史查看查看某次提交
    git show HEAD
    • commit-hash 指定提交
    • --stat 文件统计
    • --name-only 仅文件名

    展示指定提交的详细变更。

  • 历史查看逐行追溯
    git blame file.js
    • -L 10,20 指定行范围
    • -w 忽略空白变更

    查看每一行代码最后由哪次提交修改。

  • 分支管理分支列表 / 创建
    git branch -a
    • -a 含远程分支
    • branch-name 创建分支
    • -d 删除已合并分支
    • -D 强制删除
    • -m 重命名

    管理本地与远程分支引用。

  • 分支管理切换分支
    git switch feature/login
    • -c 创建并切换
    • - 切回上一分支
    • git checkout 旧版等效命令

    切换到已有分支或创建新分支。

  • 分支管理合并分支
    git merge feature/login
    • --no-ff 保留合并提交
    • --squash 压缩为一次提交
    • -m 合并说明

    将指定分支历史并入当前分支。

  • 分支管理变基
    git rebase main
    • -i 交互式整理提交
    • --continue 解决冲突后继续
    • --abort 放弃变基
    • main onto 指定基底

    将当前分支提交重新应用到目标分支顶端，历史更线性。

  • 远程同步拉取
    git pull --rebase origin main
    • --rebase 变基拉取
    • --ff-only 仅快进
    • origin 远程名
    • main 分支名

    从远程获取并合并到当前分支。

  • 远程同步推送
    git push -u origin main
    • -u 设置上游分支
    • --force-with-lease 安全强推
    • --tags 推送标签
    • origin branch 指定远程与分支

    将本地提交上传到远程仓库。

  • 远程同步获取远程
    git fetch --all --prune
    • --all 所有远程
    • --prune 清理已删远程分支
    • origin 指定远程

    下载远程更新但不自动合并到当前分支。

  • 远程同步远程仓库
    git remote -v
    • add name url 添加
    • set-url name url 修改地址
    • remove name 删除

    查看与管理远程仓库地址。

  • 暂存与恢复临时保存修改
    git stash push -m "wip"
    • list 列表
    • pop 恢复并删除
    • apply 恢复不删除
    • drop 丢弃
    • stash@{n} 指定条目

    暂存未提交改动以便切换分支。

  • 撤销与回退重置
    git reset --soft HEAD~1
    • --soft 保留工作区与暂存
    • --mixed 默认保留工作区
    • --hard 全部丢弃（危险）
    • HEAD~1 回退 1 次提交

    移动 HEAD 指针并可选清理暂存区与工作区。

  • 撤销与回退恢复文件
    git restore file.js
    • --staged 取消暂存
    • git checkout -- file 旧写法
    • . 恢复全部工作区

    丢弃工作区修改或从暂存区撤出文件。

  • 撤销与回退反向提交
    git revert HEAD
    • --no-commit 仅改动不提交
    • commit-hash 指定提交
    • -m 1 合并提交选主线

    通过新提交撤销某次历史变更，适合已推送的提交。

  • 撤销与回退挑选提交
    git cherry-pick abc1234
    • -n 不自动提交
    • --continue 解决冲突后继续
    • A..B 范围挑选

    将其他分支的指定提交应用到当前分支。

  • 标签打标签
    git tag -a v1.0.0 -m "release 1.0.0"
    • -a 附注标签
    • -d 删除标签
    • git push origin v1.0.0 推送标签
    • --list 列出标签

    为重要版本创建可读标签。

  • 清理清理未跟踪文件
    git clean -fd
    • -n 试运行
    • -f 强制
    • -d 含目录
    • -x 含 .gitignore 忽略的文件

    删除未跟踪文件，操作前建议先用 -n 预览。

git switch 和 git checkout 有什么区别？

Git 2.23+ 推荐用 switch 切换分支、restore 恢复文件；checkout 仍可用但职责更混杂。
