Excel 常用公式

搜索
分组
类型

共 65 条

  • 基础函数公式求和
    =SUM(A1:A10)

    对区域求和；空单元格与文本会被忽略。

  • 基础函数公式平均值
    =AVERAGE(A1:A10)

    计算算术平均值，忽略空单元格与文本。

  • 基础函数公式计数（数字）
    =COUNT(A1:A10)

    只统计数字单元格；COUNTA 统计非空，COUNTBLANK 统计空白。

  • 基础函数公式计数（非空）
    =COUNTA(A1:A10)

    统计非空单元格数量，含文本与数字。

  • 基础函数公式最大 / 最小值
    =MAX(A1:A10)

    MAX 取最大值，MIN 取最小值；LARGE / SMALL 可取第 N 大/小。

  • 基础函数公式四舍五入
    =ROUND(A1, 2)

    ROUND 四舍五入，ROUNDUP 向上，ROUNDDOWN 向下；第二参数为小数位数。

  • 基础函数公式绝对值 / 取余
    =ABS(A1)

    ABS 绝对值，MOD 取余数，INT 向下取整，TRUNC 截断小数。

  • 条件统计公式单条件求和
    =SUMIF(A:A, "华东", B:B)

    在 A 列匹配条件后对 B 列求和；条件可用通配符 * 与 ?。

  • 条件统计公式多条件求和
    =SUMIFS(C:C, A:A, "华东", B:B, ">100")

    SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, …)。

  • 条件统计公式单条件计数
    =COUNTIF(A:A, ">60")

    统计满足条件的单元格数量，条件写法与 SUMIF 相同。

  • 条件统计公式多条件计数
    =COUNTIFS(A:A, "华东", B:B, ">100")

    多组区域与条件必须成对出现，全部满足才计数。

  • 条件统计公式条件平均
    =AVERAGEIF(A:A, ">0", B:B)

    AVERAGEIFS 支持多条件，语法类似 SUMIFS。

  • 查找引用公式垂直查找
    =VLOOKUP(E2, A:B, 2, FALSE)

    在区域首列匹配查找值并返回指定列；精确匹配请将最后一参数设为 FALSE。

  • 查找引用公式水平查找
    =HLOOKUP(E2, A1:F2, 2, FALSE)

    在区域首行匹配，返回指定行；适合表头横向排列的数据。

  • 查找引用公式新版查找
    =XLOOKUP(E2, A:A, B:B, "未找到")

    Microsoft 365 可用，支持左右查找、近似匹配与默认值。

  • 查找引用公式匹配位置
    =MATCH(E2, A:A, 0)

    返回查找值在区域中的位置；0 精确，1 升序近似，-1 降序近似。

  • 查找引用公式INDEX + MATCH
    =INDEX(B:B, MATCH(E2, A:A, 0))

    经典组合查找，可向左查找，比 VLOOKUP 更灵活。

  • 查找引用公式按位置取值
    =INDEX(A1:C10, 3, 2)

    返回区域第 3 行第 2 列的值；行/列号可嵌套 MATCH。

  • 查找引用公式间接引用
    =INDIRECT("Sheet2!A1")

    通过文本构造引用地址，动态引用其他工作表单元格。

  • 查找引用公式偏移引用
    =OFFSET(A1, 2, 1, 5, 1)

    从起点偏移行/列并返回指定高宽的引用区域。

  • 查找引用公式按序号取值
    =CHOOSE(2, "甲", "乙", "丙")

    根据索引号从值列表中返回对应项，索引从 1 开始。

  • 文本处理公式拼接文本
    =CONCAT(A1, "-", B1)

    CONCAT / CONCATENATE 连接多个文本；365 推荐 TEXTJOIN。

  • 文本处理公式带分隔符拼接
    =TEXTJOIN(", ", TRUE, A1:A5)

    第二参数 TRUE 忽略空单元格；适合合并一列非空值。

  • 文本处理公式截取文本
    =LEFT(A1, 3)

    LEFT / RIGHT / MID 从指定位置截取；配合 LEN 计算长度。

  • 文本处理公式文本长度
    =LEN(A1)

    返回字符数；LENB 按字节计（双字节字符算 2）。

  • 文本处理公式查找子串位置
    =FIND("-", A1)

    FIND 区分大小写，SEARCH 支持通配符；找不到返回 #VALUE!。

  • 文本处理公式替换文本
    =SUBSTITUTE(A1, "旧", "新")

    SUBSTITUTE 可指定替换第几次；REPLACE 按位置替换固定长度。

  • 文本处理公式清理空格
    =TRIM(A1)

    去除首尾空格并合并中间多余空格，导入数据后常用。

  • 文本处理公式数字转文本格式
    =TEXT(NOW(), "yyyy-mm-dd")

    按格式代码把数值格式化为文本显示，不改变原单元格值。

  • 文本处理公式文本转数字
    =VALUE(A1)

    将文本数字转为数值；也可用双负号 -- 或 *1 强制转换。

  • 日期时间公式当前日期 / 时间
    =TODAY()

    TODAY 返回日期，NOW 返回日期时间；打开文件时会重新计算。

  • 日期时间公式提取年 / 月 / 日
    =YEAR(A1)

    YEAR / MONTH / DAY 从日期中提取组成部分；HOUR / MINUTE / SECOND 同理。

  • 日期时间公式日期差
    =DATEDIF(A1, B1, "D")

    计算两日期间的天数/月数/年数，第三参数 Y/M/D/YM/YD 等指定单位。

  • 日期时间公式月末日期
    =EOMONTH(A1, 0)

    返回指定日期所在月的最后一天，0 为本月，1 为下月月末。

  • 日期时间公式偏移月份
    =EDATE(A1, 3)

    在日期上加/减指定月数，常用于账期与到期日计算。

  • 日期时间公式工作日天数
    =NETWORKDAYS(A1, B1)

    排除周末的工作日数；NETWORKDAYS.INTL 可自定义周末规则。

  • 日期时间公式构造日期
    =DATE(2024, 6, 1)

    由年、月、日数字组合成日期序列值。

  • 逻辑判断公式条件判断
    =IF(A1>60, "及格", "不及格")

    经典二分支；多条件请用 IFS 或嵌套 IF。

  • 逻辑判断公式多条件判断
    =IFS(A1>=90, "优", A1>=60, "及格", TRUE, "不及格")

    按顺序匹配条件，返回第一个为真的结果；末尾可用 TRUE 作默认。

  • 逻辑判断公式等值分支
    =SWITCH(A1, 1, "一", 2, "二", "其他")

    将表达式与多个值逐一比较，适合固定枚举映射。

  • 逻辑判断公式与 / 或
    =AND(A1>0, B1>0)

    AND 全为真才真，OR 任一为真即真，常嵌套在 IF 中。

  • 逻辑判断公式捕获错误
    =IFERROR(VLOOKUP(E2, A:B, 2, FALSE), "")

    公式出错时返回指定值；IFNA 仅捕获 #N/A。

  • 逻辑判断公式是否空白
    =ISBLANK(A1)

    ISNUMBER / ISTEXT / ISERROR 等可判断单元格类型与状态。

  • 统计汇总公式分类汇总
    =SUBTOTAL(9, A1:A10)

    9 代表 SUM，配合筛选时只汇总可见行；1-11 对应不同统计函数。

  • 统计汇总公式排名
    =RANK(A1, A:A, 0)

    RANK 降序排名；RANK.EQ / RANK.AVG 处理并列名次方式不同。

  • 统计汇总公式中位数 / 标准差
    =MEDIAN(A1:A10)

    MEDIAN 中位数，STDEV.S 样本标准差，VAR.S 样本方差。

  • 数组函数公式去重列表
    =UNIQUE(A2:A100)

    Microsoft 365 动态数组，返回唯一值列表，可溢出到下方单元格。

  • 数组函数公式筛选数组
    =FILTER(A2:C100, B2:B100="华东")

    按条件筛选多列数据；条件可写 (B2:B100="华东")*(C2:C100>100) 表示 AND。

  • 数组函数公式排序数组
    =SORT(A2:C100, 2, -1)

    SORT 按列排序，-1 降序；SORTBY 可按另一列排序。

  • 数组函数公式按其他列排序
    =SORTBY(A2:A100, B2:B100, 1)

    主区域与排序依据列长度须一致。

  • 数组函数公式生成序列
    =SEQUENCE(10, 1, 1, 1)

    生成连续数字矩阵：行数、列数、起始值、步长。

  • 数组函数公式行列转置
    =TRANSPOSE(A1:D1)

    365 可自动溢出；旧版需 Ctrl+Shift+Enter 数组公式。

  • 数组函数公式命名中间变量
    =LET(x, A1*2, y, x+10, y)

    Microsoft 365 可用，简化复杂公式并提升可读性与性能。

  • 快捷键快捷键复制 / 粘贴
    Ctrl + C · Ctrl + V

    macOS 为 Cmd + C / Cmd + V；Ctrl + X 剪切，Ctrl + Z 撤销。

  • 快捷键快捷键向下 / 向右填充
    Ctrl + D · Ctrl + R

    Ctrl + D 复制上一行内容向下填充，Ctrl + R 向右填充。

  • 快捷键快捷键自动求和
    Alt + =

    在选中区域下方或右侧插入 SUM 公式。

  • 快捷键快捷键绝对引用
    F4

    编辑公式时在 A1 / $A$1 / A$1 / $A1 引用样式间切换。

  • 快捷键快捷键定位
    Ctrl + G

    打开定位对话框，可跳转到单元格或选择可见单元格、空值等。

  • 快捷键快捷键筛选
    Ctrl + Shift + L

    为当前区域开启或关闭自动筛选。

  • 快捷键快捷键保存 / 另存为
    Ctrl + S · F12

    Ctrl + S 保存工作簿，F12 另存为。

  • 快捷键快捷键插入日期 / 时间
    Ctrl + ; · Ctrl + Shift + ;

    Ctrl + ; 当前日期，Ctrl + Shift + ; 当前时间（静态值，非公式）。

  • 快捷键快捷键单元格格式
    Ctrl + 1

    打开「设置单元格格式」对话框，调整数字、对齐、边框等。

  • 快捷键快捷键快速跳转
    Ctrl + Home · Ctrl + End

    Ctrl + Home 到 A1，Ctrl + End 到最后有数据的单元格。

  • 快捷键快捷键扩展选区
    Ctrl + Shift + 方向键

    从当前单元格扩展到连续有数据的区域边缘。

  • 快捷键快捷键单元格内换行
    Alt + Enter

    在单元格编辑状态下插入换行，而非确认输入。

常见问题

点击问题展开或收起答案

VLOOKUP 为什么返回 #N/A？

常见原因是查找值不存在、查找列不是区域第一列，或最后一参数用了 TRUE 近似匹配。可改用 XLOOKUP 或 IFERROR 处理。

快捷键在 Mac 上一样吗？

多数情况下 Ctrl 对应 Cmd，例如复制粘贴为 Cmd + C / Cmd + V；部分功能键如 F4 行为可能因键盘设置不同而略有差异。
