CSP Header 生成

场景预设

指令配置

常用来源用多选框勾选；简单指令用下拉框；CDN 等自定义域名填在下方输入框。

default-src默认兜底策略；未单独指定的资源类型均遵循此规则。
自定义域名（空格分隔）
script-src允许加载 JavaScript 的来源，包括外链脚本与内联脚本策略。
自定义域名（空格分隔）
style-src允许加载 CSS 的来源，包括外链样式表与内联 style。
自定义域名（空格分隔）
img-src允许加载图片的来源，如 img、picture、部分 CSS 背景图。
自定义域名（空格分隔）
connect-src允许 fetch、XHR、WebSocket、EventSource 等网络连接的目标地址。
自定义域名（空格分隔）
font-src允许 @font-face 等字体文件的加载来源。
自定义域名（空格分隔）
object-src允许 object、embed 等插件内容；通常设为 none 以禁用 Flash 等。
frame-ancestors允许哪些页面通过 iframe 嵌入本站；仅 HTTP 响应头生效，meta 无效。
base-uri限制页面中 base 标签可设置的基准 URL，防止基准地址被篡改。
form-action限制表单可提交到的 URL，防止表单被劫持到恶意站点。
report-uri（可选）CSP 违规上报地址；浏览器会将拦截事件 POST 到该 URL（可选）。

HTTP 响应头

Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self'; connect-src 'self'; font-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'

HTML meta 标签

frame-ancestors 等部分指令不能通过 meta 生效，生产环境请优先配置 HTTP 响应头。

<meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self'; connect-src 'self'; font-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'">

按常见场景生成 Content-Security-Policy 响应头与 meta 标签，部署前请按实际资源白名单调整。

使用说明

帮助快速搭建内容安全策略白名单。部署前请按实际脚本、样式与接口域名调整各指令来源。

  1. 01选择场景预设。
  2. 02按需修改 default-src、script-src 等指令。
  3. 03复制 HTTP Header 值或 meta 标签。

为什么页面脚本被 CSP 拦截？

script-src 未包含实际脚本来源；内联脚本需 nonce/hash 或调整策略，不建议长期使用 unsafe-inline。
