人脸检测

01 / 选择图片

在浏览器本地检测人脸位置与置信度，不进行身份识别；图片与视频均不会上传。

02 / 检测结果

请选择图片或开启视频检测。

检测结果仅供调试与辅助参考，不应用于身份认证或执法场景。

使用说明

适合调试摄像头、检查合影或预览人脸框效果。图片模式可批量检测；视频模式开启摄像头后实时叠加检测框。所有处理均在本地完成。

  1. 01选择「图片检测」或「视频流检测」模式。
  2. 02图片：上传 PNG/JPG/WebP，点击检测当前图片或检测全部。
  3. 03视频：点击开始检测并允许摄像头权限，查看实时人脸框与数量。
  4. 04需要时可复制检测报告。

常见问题

点击问题展开或收起答案

能否识别具体是谁？

不能。本工具只检测人脸位置与置信度，不提供身份识别或人脸比对功能。

视频模式为什么帧率不高？

为降低 CPU 占用，视频流检测按固定间隔采样，并非逐帧检测。

数据会上传吗？

不会。模型推理与摄像头画面均在浏览器本地处理，不会上传到服务器。
