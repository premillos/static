JWT 解析

JWT 字符串

仅解析结构与声明，不验证签名，也不会上传令牌。

使用说明

粘贴 JWT 字符串即可查看解码后的 Header 与 Payload，并格式化 exp、iat 等时间字段。

  1. 01粘贴完整的 JWT 字符串。
  2. 02点击解析 JWT。
  3. 03查看 Header、Payload 与 Signature 分区内容。

工具会验证 JWT 签名吗？

不会。此工具仅做 Base64URL 解码与 JSON 展示，不提供密钥验签，请勿在公共环境粘贴生产令牌。
