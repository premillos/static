02 / 设置与导出

输出格式
输出画质 · 85%

图片不会上传，处理速度取决于图片大小和设备性能。

使用说明

需要兼容更多设备时选择 JPG，需要透明背景时选择 PNG，想兼顾体积和透明度时选择 WebP 或 AVIF。默认保持原图尺寸，也可在转换时按最长边缩小；你可以直接预览和下载结果。

  1. 01点击或拖拽选择一张或多张静态 PNG、JPG 或 WebP，也可直接拖入文件夹，单张最大 20 MB、一次最多 50 张。
  2. 02选择输出格式（含 AVIF）；JPG / WebP / AVIF 可调整画质，JPG 可设置透明区背景色；需要时可勾选「转换时缩小尺寸」。
  3. 03点击开始处理，点击结果缩略图可放大预览，再下载单张或 ZIP。

常见问题

点击问题展开或收起答案

PNG 转 JPG 后透明背景会怎样？

JPG 不支持透明通道。工具会使用你选择的背景色填充透明区域，默认是白色；需要保留透明时请选择 PNG 或 WebP。

图片转换会改变分辨率或保留元数据吗？

默认保持原图像素尺寸；勾选「转换时缩小尺寸」后按最长边等比缩小（只缩不放）。重新编码通常不保留原文件元数据。JPG、WebP、AVIF 是有损输出；PNG 使用无损编码。动图请使用专门的动图转换工具。

AVIF 是什么？哪些浏览器支持？

AVIF 是体积通常更小的现代图片格式，适合网页分发。导出依赖浏览器对 Canvas AVIF 编码的支持，请使用新版 Chrome 或 Edge；若失败可改用 WebP。
