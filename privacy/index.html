概述

工具工坊（以下简称「本站」）提供可在浏览器中使用的在线实用工具。我们设计产品的首要目标，是让你快速完成一件具体的小事，而不是收集或使用你的个人数据。

本页说明我们如何处理（以及不如何处理）你在使用本站时可能涉及的信息。若某工具页面另有更具体的限制，以该工具说明为准。

数据如何处理

当前已上线的工具均在浏览器本地执行主要逻辑。你选择的文件、输入的文本、设置的参数会在设备内存中参与计算，处理完成后由你自行复制、预览或下载结果。

图片类工具不会把图片上传到我们的服务器。文本、编码、格式化、校验类工具同样不在后台持久化你的输入。涉及网络请求的功能（若未来出现）会在对应工具页面明确标注，并在上线前更新本页。

  • 图片处理：解码、转换、压缩、裁切与打包下载在本地完成。
  • 文本与结构化数据：JSON、YAML、SQL、Markdown 等转换与预览在本地完成。
  • 加密与哈希：密钥与明文仅在当前页面会话中使用，不会发送到我们的服务器。
  • EXIF 查看与去除：元数据读取与导出在本地完成；导出文件会移除已识别的元数据字段。

我们不会收集什么

除非法律要求或你在未来版本中明确同意，我们不会主动收集、购买或出售以下信息：

  • 你上传、粘贴或输入的文件内容与文本内容
  • 工具生成的输出结果、下载记录或处理参数
  • 可用于直接识别个人身份的证件号码、令牌、密码或密钥
  • 精确地理位置、通讯录、相册等设备权限数据

浏览器本地存储

为改善使用体验，本站可能在浏览器本地存储少量偏好设置，例如浅色 / 暗色 / 跟随系统主题。这类数据仅保存在你的设备上，用于下次访问时恢复界面偏好。

若浏览器处于隐私模式、禁用存储或配额不足，偏好可能无法保存，但不影响工具的基本功能。我们不会把 localStorage 中的偏好与工具输入内容关联上传。

服务器日志与统计

本站以静态站点形式部署。访问页面时，托管平台（如 GitHub Pages）可能按平台默认策略记录基础的访问日志，例如请求的 URL、时间、User-Agent 与响应状态。我们无法通过这些日志读取你的工具输入内容。

当前版本未集成第三方广告或跨站用户画像统计。若未来引入访问统计，我们会在此处说明用途、数据范围，并提供尽可能克制的配置。

安全实践

我们在前端实现中遵循以下原则，降低误用与泄露风险：

  • Markdown 等需要 HTML 预览的内容，经净化后再展示，避免不可信输入直接执行脚本。
  • 不在前端源码或构建产物中存放服务端密钥；浏览器端加密工具不能替代专业的密钥管理方案。
  • 证件校验、JWT 解析等工具仅做格式或结构分析，不联网查询真伪，也不验证第三方签名密钥。
  • 处理失败时保留你的输入，并给出可理解的错误提示，而不是静默丢弃或覆盖。

第三方依赖

部分工具在运行时按需加载开源 JavaScript 库（例如 Markdown 渲染、YAML 解析、二维码生成、EXIF 读取等）。这些库随构建产物一起分发，由浏览器下载并在本地执行，不会把你的输入发送到库的维护者服务器。

请仅在可信环境中处理敏感信息。公共或共享设备上使用后，建议关闭页面并自行清理下载文件。

你的控制与建议

你可以通过以下方式降低使用在线工具时的风险：

  • 处理机密文档、生产密钥或真实证件前，优先在离线、受控环境中评估是否适用浏览器工具。
  • 使用完成后清空输入、关闭标签页，并删除不再需要的下载文件。
  • 在分享结果前检查是否仍包含敏感元数据（例如图片 EXIF、HTTP 头中的内部标识）。

未成年人

本站面向具有基本网络使用能力的用户。若未成年人使用本站，建议在监护人指导下进行，并避免输入真实身份信息或账户凭据。

政策更新

当我们新增会改变数据处理方式的工具，或调整本地存储、统计策略时，会更新本页并在变更记录中注明。继续使用本站即表示你阅读并理解当时生效的版本。

若你对本页内容有疑问或发现与实际行为不一致，欢迎通过项目仓库的 Issue 反馈，我们会尽快核对并修正说明。

我们持续以「本地可用、说明透明、默认不收集」为原则维护工具工坊。
